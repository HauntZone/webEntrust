# 静态网页托管平台

一个多用户静态网站托管服务。用户自己注册、上传一个 zip 压缩包，立刻得到一个可以分享的网址；访客打开链接就能看，不需要账号；管理员在后台维护。

除 Express 和一个 ZIP 读取库外，**没有任何额外依赖**——没有模板引擎、没有数据库、没有构建步骤。`npm start` 就能跑。

---

## 快速开始

```bash
npm install      # 依赖已装好，改过 package.json 才需要重跑
npm start        # 默认 http://localhost:3000
```

打开首页 → 「点此初始化」→ 设定管理员账号。

> **第一次务必设置 `SESSION_SECRET`**，否则每次重启都会生成随机密钥，所有人都被登出。

```bash
# Windows (PowerShell)
$env:SESSION_SECRET="换成一串你自己的随机字符串"; npm start
# Linux / macOS
SESSION_SECRET="换成一串你自己的随机字符串" npm start
```

## 三种角色

| 角色 | 能做什么 | 怎么进 |
|---|---|---|
| **访客** | 打开 `/别名/文件夹/` 阅读网页 | 不需要账号 |
| **用户** | 注册、上传 zip 发布站点、删除站点、单独开关自己的外链功能 | `/register` 自助注册 |
| **管理员** | 用户管理、改配额、禁用账号、强制下线、删除用户、全局外链开关、保留别名 | 与用户**同一个登录入口**，登录后多出管理菜单 |

## 用法

### 用户：发布一个站点

1. 把网页文件打包成 zip（**压缩包根目录要直接是 `index.html`**，不要多套一层文件夹）
2. `/dashboard` → 填文件夹名 → 选 zip → 上传
3. 访问 `https://你的域名/你的别名/文件夹名/`

**访问规则：**

- 站点 URL 是 `/<别名>/<文件夹>/`，别名是注册时定的，**注册后不可更改**
- 别名只能用小写字母、数字和短横线，3–30 位，必须以字母开头
- 文件夹名同理，1–31 位
- 目录下必须有 `index.html`，否则返回 404（**不列目录**，避免暴露文件结构）
- **重名上传 = 整站覆盖**：先清空该文件夹再解压，旧文件不会残留占配额
- 要回收配额就删掉整个文件夹

### 管理员：日常维护

后台在 `/admin`：

- **用户列表** —— 别名、角色、状态、实时用量、注册时间
- **禁用 / 启用** —— 禁用后该用户无法登录，**且他的站点立即停止服务（返回 404）**
- **强制下线** —— 让该用户所有已登录的浏览器立刻失效
- **删除用户** —— 连同磁盘上的站点文件一起清掉
- **改配额 / 重置密码** —— 按别名操作
- 系统里**唯一的管理员不能被禁用或删除**，防止把自己锁在外面

`/admin/settings` 管两个全局开关和保留别名清单。

### 外链功能

访客点击用户页面里的**站外链接**时，可以拦一下。两个独立开关：

- **外链警告** —— 弹出「即将离开本站」确认框
- **外链引导** —— 经过一个中转页，页面上明写目标域名，访客可以继续或取消

**两级控制**：管理员有全局总开关，用户可以对自己的站点单独设置，但**用户开不起来被管理员全局关掉的功能**。

> ⚠️ **这不是安全边界，只是礼貌性提醒。** 以下都能绕过：链接上按 Ctrl/中键在新标签打开、访客禁用 JS、用户页面自带 CSP 禁止外链脚本、以及图片/样式/iframe 这类子资源（它们照旧直连外站）。别把它当防护措施。

## 部署

**反向代理**：平台会识别 `X-Forwarded-Proto: https`，并据此给 Cookie 加 `Secure`。Nginx 示例：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Real-IP $remote_addr;
    client_max_body_size 100m;   # 别小于上传上限
}
```

**只支持单进程单实例。** 数据存在 JSON 文件里，写队列是进程内的，`pm2 -i max` 或开多个实例会让数据互相覆盖。要扩容得先换存储层。

**注册是开放的自助注册。** 不想要公开注册的话，得自己加一层准入（比如注册码），或在反代上限制 `/register`。

## 数据与重置

运行时数据在两个地方，互相独立：

| 路径 | 内容 |
|---|---|
| `data/users.json` | 账号（口令用 scrypt 散列） |
| `data/meta.json` | 全局外链开关、默认配额 |
| `data/reserved-aliases.json` | 保留别名清单 |
| `data/tmp/` | 上传临时文件与解压中转目录 |
| `public/<别名>/` | 用户上传的站点内容 |

**重置粒度：**

| 想重置什么 | 删什么 |
|---|---|
| 全部账号 + 站点 + 设置 | `data/` + `public/` 下所有用户目录 |
| 只清账号（保留全局设置） | `data/users.json` |
| 只重置全局开关 / 默认配额 | `data/meta.json` |
| 只清某个用户的站点 | `public/<他的别名>/` |
| 重置保留别名清单 | `data/reserved-aliases.json` |

**完全重置：**

```bash
# 1. 先停服务器（Ctrl+C）。必须先停，写队列在进程内，边跑边删会被写回来
# 2. 清账号、配置、临时目录
rm -rf data
# 3. 清所有用户上传的站点内容
rm -rf public/*
# 4. 重启
npm start
```

`data/meta.json` 和 `data/reserved-aliases.json` 会在启动时用默认值自动重建；`users.json` 等第一次注册或建管理员时才生成。

> ⚠️ 注册页已经写明本项目不对用户信息做加密存储、项目可能随时移除。口令本身用 scrypt 散列存储，但**别把它当可靠的服务来用**。

## 依赖与许可

| 包 | 许可证 | 用途 |
|---|---|---|
| `express` | MIT | Web 框架 |
| `yauzl` | **MIT** | ZIP 流式读取 |
| `pend` | **MIT** | yauzl 的唯一依赖 |
| `cookie-parser` / `morgan` / `debug` / `http-errors` | MIT | Express 脚手架自带 |

全部为宽松许可，可免费商用。

**关于 ZIP 库的选型**：`adm-zip` 和 `jszip` 虽然也是 MIT，但都是**全内存模型**——整个压缩包先读进内存再写盘，恶意压缩包能在你掐断之前撑爆内存。`yauzl` 提供逐条目流（`openReadStream()`），才能做到边解压边按实际字节数计配额、超了立刻掐断。

## 已知限制

- **外链拦截可被绕过**（见上文），属礼貌性功能
- **`/go` 是开放重定向**——只放行 http/https 且页面明示目标域名，这是功能本身
- **不支持多进程 / 多实例**
- **用户页面自带 CSP**（禁内联或外域脚本）时外链脚本会静默失效，服务端无法干预
- **不支持自定义域名**，所有站点共用同一域名下的路径前缀
- 未做备份、限流、日志归档；用户用量按磁盘实时统计，用户多了后台会变慢
